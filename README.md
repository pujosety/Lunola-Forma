## Development status

Windows x64 is the current build target. The underlying engine identifies this development line as **5.4.0 Alpha**; it is not a stable release.

This fork changes presentation while keeping `.blend`, `bpy`, add-on interfaces, engine identifiers and keymaps intact. Executable names remain `blender.exe` and `blender-launcher.exe` for compatibility.

See the [implementation report](docs/lunola/IMPLEMENTATION.md), [build report](docs/lunola/BUILD_REPORT.md), and [executed test results](docs/lunola/TEST_RESULTS.md). Source/asset checks, compiled builds and runtime verification are recorded separately.
