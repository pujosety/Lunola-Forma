# Security

## Development status

Lunola Forma is an alpha development fork. No stable security-support window, response SLA or supported-version policy has been established yet.

## Report a vulnerability privately

Do not publish credentials, private project files, exploit-ready details or customer data in a public issue. A dedicated private reporting address has not been configured. Before disclosing details, confirm an approved private channel with the repository owner. GitHub private vulnerability reporting must be enabled and checked before it is offered as a reporting route.

Describe the affected version/hash, environment, reproduction steps and potential impact. Use a minimal nonconfidential example.

## Protect your workspace

Only open trusted project files and scripts. Review add-ons before installing them. Verification runs use factory startup, isolated user directories and disabled script auto-execution; that test setup is not a guarantee arbitrary downloaded projects are safe.

Do not commit passwords, tokens, signing keys, private certificates, user preferences or personal crash dumps. Release signing, a clean-machine installation test, and dependency inventory review remain separate release gates.
