# Lunola Forma

**by Pujo Setyo**

**Professional 3D Creation Suite**

Build a world of your own.

Model a character, explore a material, or bring a scene to life. Lunola Forma brings modeling, animation, and rendering into one 3D workspace, with a colorful identity from Lunola.

## Start creating

Open a new scene, shape your objects, and experiment with light. Keep your work in `.blend` files so you can return to it, share it, and continue building.

## This build

The current development line is based on version **5.4.0 Alpha**. It is not a stable release. Keep backups of important projects and test your add-ons before relying on this build for production work.

Windows x64 is the verified build platform. Baseline and Phase C builds passed the project's 12-case smoke suite. The build with the new splash and native icons is being verified separately; those earlier passes do not certify this later build.

Product guides live here. Engineering evidence remains in [the implementation report](../IMPLEMENTATION.md), [build report](../BUILD_REPORT.md), and [test results](../TEST_RESULTS.md).
